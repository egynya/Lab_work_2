# Документация проекта `geometric_lib`

## Общее описание решения

Проект представляет собой библиотеку для вычисления **площади** и **периметра** геометрических фигур.

Реализованы два модуля:

* `square.py` — функции для работы с квадратом;
* `circle.py` — функции для работы с кругом.
* `triangle.py` — функции для работы с треугольником;
* `rectangle.py` — функции для работы с прямоугольником.

Все функции принимают целые или вещественные числа и возвращают числовой результат.

---

## Описание функций

### `area(a)` — площадь квадрата

Возвращает площадь квадрата по длине его стороны.

**Параметры:**

* `a` (`float`) — длина стороны квадрата.

**Возвращаемое значение:**

* `float` — площадь квадрата.

**Пример вызова:**

```python
from square import area

result = area(5)
print(result)
# Ожидаемый вывод: 25
```

---

### `perimeter(a)` — периметр квадрата

Возвращает периметр квадрата по длине его стороны.

**Параметры:**

* `a` (`float`) — длина стороны квадрата.

**Возвращаемое значение:**

* `float` — периметр квадрата.

**Пример вызова:**

```python
from square import perimeter

result = perimeter(5)
print(result)
# Ожидаемый вывод: 20
```

---

### `area(r)` — площадь круга

Возвращает площадь круга по его радиусу.

**Параметры:**

* `r` (`float`) — радиус круга.

**Возвращаемое значение:**

* `float` — площадь круга.

**Пример вызова:**

```python
from circle import area

result = area(3)
print(result)
# Ожидаемый вывод: 28.274333882308138
```

---

### `perimeter(r)` — длина окружности

Возвращает длину окружности по её радиусу.

**Параметры:**

* `r` (`float`) — радиус круга.

**Возвращаемое значение:**

* `float` — длина окружности.

**Пример вызова:**

```python
from circle import perimeter

result = perimeter(3)
print(result)
# Ожидаемый вывод: 18.84955592153876
```

---

### `area(a, b)` — площадь прямоугольника

Возвращает площадь квадрата по длине его сторон.

**Параметры:**

* `a` (`float`) — длина одной стороны прямоугольника.
* `b` (`float`) — длина иной стороны прямоугольника.

**Возвращаемое значение:**

* `float` — площадь прямоугольника.

**Пример вызова:**

```python
from rectangle import area

result = area(5, 6)
print(result)
# Ожидаемый вывод: 30
```

---

### `perimeter(a, b)` — периметр прямоугольника

Возвращает периметр прямоугольника по длине его сторон.

**Параметры:**

* `a` (`float`) — длина одной стороны прямоугольника.
* `b` (`float`) — длина иной стороны прямоугольника.

**Возвращаемое значение:**

* `float` — периметр прямоугольника.

**Пример вызова:**

```python
from rectangle import perimeter

result = perimeter(5, 6)
print(result)
# Ожидаемый вывод: 22
```

---

### `area(a, h)` — площадь треугольника

Возвращает площадь треугольника по длине его стороны и длине высоты, опущенной к этой стороне.

**Параметры:**

* `a` (`float`) — длина стороны треугольника.
* `h` (`float`) — длина высоты опущенной на эту сторону треугольника.

**Возвращаемое значение:**

* `float` — площадь треугольника.

**Пример вызова:**

```python
from triangle import area

result = area(5, 6)
print(result)
# Ожидаемый вывод: 15
```

---

### `perimeter(a, b, c)` — периметр треугольника

Возвращает периметр треугольника по длине его сторон.

**Параметры:**

* `a` (`float`) — длина одной стороны треугольника.
* `b` (`float`) — длина второй стороны треугольника.
* `c` (`float`) — длина третьей стороны треугольника.

**Возвращаемое значение:**

* `float` — периметр треугольника.

**Пример вызова:**

```python
from triangle import perimeter

result = perimeter(5, 6, 6)
print(result)
# Ожидаемый вывод: 17
```
